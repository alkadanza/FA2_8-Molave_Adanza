# Distance of two points

## Description
- The program first asks the user for the coordinates of two points and then the code calculates the distance of the two points and shows the output.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- x1
- x2
- y1
- y2

## Sample Output

Enter the x-coordinate of the second point (x2): 4 

Enter the x-coordinate of the first point (x1): 5

Enter the y-coordinate of the second point (y2): 7

Enter the y-coordinate of the first point (y1): 8

the distance of two points is: 1.4142135623730951
